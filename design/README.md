# Day 2 design pack — not available

This repository is a solo, single-session practice run of the Day 3 hackathon
brief, not a facilitator-assigned team submission. There is no Exercise 7
component architecture, no Exercise 8 entitlement role-play notes, and no
Day 2 presentation behind this build — those are normally produced across
Day 1 and Day 2 by a five-person team before the Day 3 build starts, and
weren't produced here.

What stands in for them: the design actually implemented is described in
`../README.md` (component-by-component) and the rule table there, built
directly from the Day 3 brief and the supplied inputs rather than from a
carried-forward design pack. Where a real submission would compare the build
against its Day 2 design and note divergence, this one has no baseline to
diverge from — that comparison is the main thing a real team's version of
this repository would add that this one cannot.
